# Şarkıfay - Modern Müzik Arama Uygulaması

![Şarkıfay Demo](./img:gif/gif/Zight%20Recording%202025-02-20%20at%2006.11.50%20PM.gif)

Şarkıfay, Spotify API'sini kullanarak modern ve kullanıcı dostu bir müzik arama deneyimi sunan web uygulamasıdır.

## Özellikler

- 🎵 Anlık müzik arama
- 🎨 Modern ve duyarlı tasarım
- ▶️ Müzik oynatma kontrolü
- 🔄 Dönen albüm kapağı animasyonu
- 🔊 Ses seviyesi kontrolü
- 📱 Mobil uyumlu arayüz
- ⏳ Yükleme animasyonları

## Teknolojiler

- HTML5
- CSS3
- JavaScript (ES6+)
- Shazam Core API
- Bootstrap Icons

3. Gerekli API anahtarını alın:

   - [RapidAPI](https://rapidapi.com/tipsters/api/shazam-core) üzerinden bir hesap oluşturun
   - Shazam Core API için bir anahtar alın
   - `js/api.js` dosyasındaki API anahtarını kendi anahtarınızla değiştirin

4. Projeyi bir web sunucusunda çalıştırın (örneğin Live Server)

## Kullanım

1. Arama çubuğuna şarkı adı veya sanatçı adı yazın
2. Sonuçlar otomatik olarak listelenecektir
3. İstediğiniz şarkının play butonuna tıklayarak dinlemeye başlayın
4. Alt kısımdaki player ile:
   - Şarkıyı duraklatıp oynatabilirsiniz
   - Ses seviyesini ayarlayabilirsiniz
   - Şarkının istediğiniz kısmına geçebilirsiniz
